Build an allowlist

Lists change. Rebuild yours from the newest snapshot before relying on it, and keep provider ranges narrow: allowing all of a cloud provider allows every customer on it.

What leaves your browser. Nothing: a daily build downloaded the providers' official range files ahead of time, and lookups and exports run in this page. Sources: Cloudflare (ips-v4, ips-v6), AWS (ip-ranges.json), Google Cloud (cloud.json), Fastly (public-ip-list), Oracle Cloud (public_ip_ranges.json) and GitHub (api.github.com/meta).
